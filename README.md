# DSA_MIT-

# Data Structures and Algorithms – Python Practicals

This repository contains my Data Structures and Algorithms practical programs implemented in Python.

The programs cover basic data structures such as Stack, Queue, Linked List, Binary Tree, and Binary Search Tree.

## Experiments

### Experiment 1 – Stack
**Library Book Return Management**

Implemented a Stack to manage returned library books using the LIFO (Last In, First Out) principle.

Operations:
- Push
- Pop
- Display

### Experiment 2 – Queue
**Ticket Booking Counter Simulation**

Implemented a Queue using a Python list to simulate customers waiting at a ticket booking counter.

Operations:
- Enqueue
- Dequeue
- Display

### Experiment 3 – Singly Linked List
**Dynamic Library Catalog**

Implemented a Singly Linked List for managing library books.

Operations:
- Insert at beginning
- Insert at end
- Delete from beginning
- Display

### Experiment 4A – Binary Tree
**Binary Tree Traversals**

Created a Binary Tree and performed recursive tree traversals.

Traversals:
- Inorder
- Preorder
- Postorder

### Experiment 4B – Binary Tree
**Library Catalog Navigation**

Implemented a Binary Tree to represent a library catalog and performed tree traversal operations.

### Experiment 5A – Binary Search Tree
**BST with Non-Recursive Traversal**

Created a Binary Search Tree and performed traversals without using recursion.

Traversals:
- Inorder
- Preorder

### Experiment 5B – Binary Search Tree
**Student Admission Record Management**

Implemented a Binary Search Tree to store student admission records.

Operations:
- Insert student record
- Search student record
- Display records using Inorder traversal
